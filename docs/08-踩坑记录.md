## 怎么记一条新坑

1. 复制 [`docs/pitfalls/_template.md`](pitfalls/_template.md) 为 `docs/pitfalls/<slug>.md`。
2. 填满八个字段；写不出 `detect` 或 `avoid` 说明还没想清楚，先留在 issue 里。
3. 把链接加到下面分类里——这一页是所有坑的唯一入口。
4. 跑 `python tools/repo-kit/check_repo.py --root .` 与 `python tools/repo-kit/generate.py --root . --write`。

## 约定

- 任何阶段踩坑，**当天回填**，不要攒。
- 同类坑合并：保留最早出现日期与最终解决方式，其余并进同一页。
- 修复与坑对应：commit message 引用坑页，如 `fix(indexer): 修正中文命中 (见 docs/pitfalls/jieba-hyphen-token.md)`。
- `status: resolved` 表示根因已消除；只是「很久没发生」应保持 `active`。
